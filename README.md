Face Recognition Attendance Management System

A web-based attendance management system developed using Python, Flask, OpenCV, and MySQL.

Features

- Face recognition-based attendance
- Manual attendance marking
- QR code-based attendance
- Student management
- Lecturer dashboard
- Attendance reports
- Timetable management
- Academic management
- User authentication

Technologies Used

Backend

- Python
- Flask
- OpenCV
- LBPH Face Recognizer
- Haar Cascade
- MySQL

Frontend

- HTML
- CSS
- JavaScript

Project Structure

- "app.py" – Main Flask application
- "routes_*.py" – Application routes
- "templates/" – HTML pages
- "static/" – CSS, JavaScript and other static files
- "requirements.txt" – Python dependencies

Note

For privacy and security reasons, face datasets and trained face-recognition model files are not included in this repository.

Purpose

This project was developed as an academic project to demonstrate practical knowledge of web application development, face recognition, database management, and attendance automation.
